# 🌿 Páramo Chingaza

Sitio web informativo desarrollado para la clase de **Programación Web – Fase 5**, 
cuyo propósito es dar a conocer el **Páramo de Chingaza**, resaltando su importancia ecológica, 
biodiversidad y atractivo turístico.

El sitio presenta información sobre la fauna, flora, ubicación y medios de contacto para visitar el páramo, 
además de ofrecer una experiencia responsive y bilingüe (español e inglés).

---

## 📌 Características

- 🌱 Información sobre la flora y fauna del Páramo de Chingaza.
- 📍 Sección de ubicación y contacto.
- 🌐 Traducción entre español e inglés.
- 📱 Diseño responsive adaptable a diferentes dispositivos.
- 🎨 Interfaz desarrollada con enfoque visual e informativo.
